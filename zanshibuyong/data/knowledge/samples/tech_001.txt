# RAG系统架构设计

## 概述
RAG（Retrieval-Augmented Generation）是一种结合检索和生成的AI架构模式。

## 核心组件

### 1. 检索器（Retriever）
- **向量检索**：使用Sentence-BERT将文本编码为向量，通过余弦相似度检索
- **关键词检索**：基于BM25算法的精确匹配
- **混合检索**：使用RRF（Reciprocal Rank Fusion）融合两种检索结果

公式：RRF_score(d) = Σ 1/(k + rank_i(d))，其中k=60

### 2. 生成器（Generator）
- 使用大语言模型（如Qwen-Max）生成回答
- 支持Function Calling动态工具调用
- 温度参数控制随机性（0-1）

### 3. 向量数据库
- 使用Chroma存储文档向量
- 支持元数据过滤
- 持久化存储

## API接口

```python
# 检索接口
retriever.retrieve(query, top_k=3)

# 生成接口
generator.generate(prompt, temperature=0.7)
```

## 性能优化
- 批量编码：batch_size=32
- 向量缓存：减少重复计算
- 异步处理：提升并发性能
