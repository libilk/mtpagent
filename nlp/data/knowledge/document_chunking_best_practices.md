# 文档分块与数据预处理最佳实践

## 概述

在RAG系统中，文档的预处理质量直接决定了检索和生成的效果上限。"垃圾进，垃圾出"（Garbage In, Garbage Out）在RAG场景中尤为明显。本文系统梳理文档解析、清洗、分块、元数据管理的全链路最佳实践。

---

## 一、文档解析（Document Parsing）

### 支持的文档格式

| 格式 | 解析工具 | 特殊处理 |
|------|----------|----------|
| PDF | pdfplumber | 表格提取 + OCR（Tesseract引擎） |
| Word (.docx) | python-docx | 保留标题层级结构 |
| Excel (.xlsx) | pandas/openpyxl | 转换为自然语言描述 |
| Markdown (.md) | 直接读取 | 保留标题层级 |
| CSV | pandas | 转换为自然语言描述 |
| 扫描件 | Tesseract OCR | 图像预处理 + 文字识别 |

### PDF解析的挑战

PDF是RAG系统中最常见也最棘手的文档格式：
- **双栏排版**：需要正确识别阅读顺序
- **表格跨页**：表格在多页之间分割，需要合并
- **扫描版PDF**：纯图片组成，必须经过OCR
- **混合内容**：文字、图片、表格混排，需要分别处理

### 乱码检测

解析后需要检测是否存在乱码：
- 中文乱码特征：大量连续的罕见Unicode字符
- 判断标准：如果非常用汉字占比超过30%，标记为疑似乱码
- 处理方式：尝试其他编码解析，或降级为OCR处理

## 二、文档清洗（Data Cleaning）

### 噪声去除

- **页眉页脚**：移除重复出现的页码、版权信息、文档标题
- **目录索引**：去除纯粹的目录页（含大量页码引用）
- **广告水印**：识别并移除嵌入的广告文本和水印标记
- **特殊字符**：标准化空白字符（全角→半角，多空格→单空格）

### 格式标准化

- 统一编码为UTF-8
- 统一换行符为\n
- 表格转换为Markdown格式或自然语言描述
- 列表标记统一为Markdown格式

## 三、文档分块（Chunking）

### 分块策略对比

| 策略 | 描述 | 适用场景 | Chunk大小建议 |
|------|------|----------|---------------|
| **固定大小** | 按字符数固定切分 | 通用场景 | 500-1000字符 |
| **递归切分** | 按段落→句子→字符层级切分 | 结构化文档 | 500-800字符 |
| **语义切分** | 用Embedding检测语义边界 | 高质量要求 | 动态大小 |
| **标题切分** | 按Markdown/HTML标题层级切分 | 技术文档 | 按章节 |
| **句子级** | 以句子为单位（用句号分隔） | 法律/合同文档 | 3-5句 |

### 分块参数调优

**chunk_size（块大小）**：
- 过大（>1500字符）：语义稀释，检索精度下降
- 过小（<200字符）：上下文不完整，生成质量下降
- 推荐：500-800字符（中文场景）

**overlap（重叠大小）**：
- 作用：保证切分边界处的上下文连续性
- 推荐：chunk_size的10-20%（如chunk_size=800时，overlap=100-150）

### 分块质量评估

好的分块应该满足：
- **语义完整**：每个chunk表达一个完整的信息单元
- **自包含**：不需要读其他chunk就能理解含义
- **颗粒度适中**：既不太笼统也不太碎片化

## 四、元数据管理（Metadata）

### 必要元数据字段

每个chunk应携带的元数据：
- `source`：原始文件路径
- `doc_id`：文档唯一标识
- `title`：文档标题
- `chunk_id`：chunk在文档内的序号
- `doc_type`：文档类型（pdf/md/docx等）

### 可选增强元数据

- `page_number`：PDF页码
- `section_title`：所属章节标题
- `creation_date`：文档创建时间
- `audience`：目标受众（技术人员/管理层/客户）
- `language`：文档语言
- `keywords`：提取的关键词列表

### 元数据在检索中的作用

元数据支持细粒度的检索过滤：
- 按文档类型过滤：只搜索技术文档
- 按时间过滤：只检索最近一年的内容
- 按受众过滤：技术问题只检索技术文档，业务问题只检索业务文档
- 按来源过滤：排除已知低质量的数据源
