# RAG系统评估与监控体系

## 概述

构建RAG系统不难，但持续保证其输出质量和稳定性是真正的挑战。本文详述RAG系统的评估指标体系、监控架构和持续优化闭环，帮助团队建立"可度量、可观测、可迭代"的质量管理实践。

---

## 一、离线评估指标

### 检索质量评估

| 指标 | 计算方式 | 说明 | 健康基准 |
|------|----------|------|----------|
| **Precision@K** | 前K个结果中相关文档的占比 | 精确率 | ≥ 0.7 |
| **Recall@K** | 所有相关文档中被检索到的占比 | 召回率 | ≥ 0.8 |
| **MRR** | 第一个相关文档排名的倒数 | 排名质量 | ≥ 0.6 |
| **NDCG@K** | 归一化折损累积增益 | 综合排名质量 | ≥ 0.65 |
| **Hit Rate** | 前K个结果中是否包含相关文档 | 命中率 | ≥ 0.9 |

### 生成质量评估

| 指标 | 方法 | 说明 |
|------|------|------|
| **Faithfulness** | LLM判断答案是否忠于检索结果 | 幻觉率的反向指标 |
| **Answer Relevance** | LLM判断答案是否切题 | 回答相关性 |
| **BLEU** | N-gram重叠度 | 与参考答案的文本匹配度 |
| **ROUGE-L** | 最长公共子序列 | 与参考答案的语义覆盖度 |
| **BERTScore** | BERT嵌入相似度 | 语义层面的相似度 |

### 端到端评估框架

推荐使用RAGAS框架进行系统化评估：
- **Context Precision**：检索到的上下文是否包含回答问题所需的信息
- **Context Recall**：回答问题所需的信息是否都被检索到
- **Faithfulness**：生成的答案是否忠于检索到的上下文
- **Answer Relevance**：生成的答案是否与问题相关

## 二、在线监控体系

### 核心监控指标

**延迟指标**：
- 检索延迟（P50/P95/P99）：向量检索 + BM25检索的总耗时
- 生成延迟：LLM推理时间
- 端到端延迟：从用户输入到返回结果的总时间
- 目标：P95 < 3秒，P99 < 5秒

**质量指标**：
- 空结果率：检索返回0结果的比例（目标 < 5%）
- 降级率：触发降级策略的比例（目标 < 3%）
- 用户满意度评分：用户主动反馈的满意度
- 重复提问率：用户对同一问题反复提问的比例（暗示答案不满意）

**系统指标**：
- 缓存命中率：语义缓存 + 检索缓存 + LLM缓存的各层命中率
- Embedding API调用量和成本
- LLM Token消耗量和成本
- 向量数据库存储量和查询QPS

### 日志结构化

全链路日志应包含以下结构化字段：
```json
{
  "trace_id": "uuid",
  "query": "用户原始问题",
  "intent": "knowledge_retrieval",
```

## 三、持续优化闭环

### 数据飞轮

```
用户查询 → 检索 → 生成 → 用户反馈
    ↑                         ↓
    ← 知识库更新 ← 质量分析 ←
```

### 优化维度

1. **知识库扩充**：根据空结果查询和低质量回答，识别知识库盲区
2. **检索调优**：分析过滤比例和排名质量，调整阈值和权重
3. **Prompt迭代**：根据幻觉率和相关性评分，优化Prompt模板
4. **模型升级**：评估新模型（Embedding和LLM）的效果提升

### A/B测试

- **检索策略对比**：纯向量 vs 混合检索的效果差异
- **模型对比**：不同LLM在特定任务上的表现
- **参数调优**：chunk_size、top_k、阈值等参数的最优值
- **样本量要求**：每组至少100个查询，确保统计显著性

## 四、告警策略

| 告警级别 | 触发条件 | 响应时间 | 处理方式 |
|----------|----------|----------|----------|
| P0（紧急） | 系统完全不可用 | 5分钟 | 立即回滚+人工介入 |
| P1（严重） | 空结果率 > 20% 或 P95延迟 > 10s | 30分钟 | 排查根因+临时降级 |
| P2（警告） | 质量评分均值 < 0.6 或 降级率 > 10% | 4小时 | 分析日志+计划优化 |
| P3（信息） | 缓存命中率 < 50% 或 成本异常 | 1天 | 周报review |
